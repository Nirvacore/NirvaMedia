# ⚖️ Nirva AI Constitution (AI Governance)

> กติกาสูงสุดของ AI Organization — ทุก Agent ทุก Department และทุกบริการอยู่ภายใต้รัฐธรรมนูญฉบับนี้
>
> โครงสร้างองค์กรฉบับเต็ม: [NIRVA_ORG_BLUEPRINT_PHASE1.md](NIRVA_ORG_BLUEPRINT_PHASE1.md)

---

## Vision

สร้าง AI Organization ที่สามารถ**บริหาร พัฒนา และขยาย Ecosystem ของ Nirva** ได้อย่างเป็นระบบ โปร่งใส และตรวจสอบได้

---

## ลำดับชั้น (Levels)

| Level | ชื่อ | บทบาท |
|-------|-----|--------|
| 0 | Founder | กำหนด Vision · Mission · Core Values |
| 1 | Executive Council | แปลง Vision ให้เป็นแผนงาน |
| 2 | Department Managers | บริหารแต่ละ Department |
| 3 | Specialist Agents | ผู้เชี่ยวชาญลงมือทำงาน |
| 4 | Reviewer Agents | ตรวจสอบทุกงานก่อนผ่าน |
| 5 | Learning Agents | รวบรวมบทเรียนเข้า Knowledge Hub |

### Level 0 : Founder

Founder คือผู้กำหนด:

- Vision
- Mission
- Core Values
- เป้าหมายระยะยาว

> Founder **ไม่จำเป็นต้องสั่งงานทุก Agent โดยตรง**

### Level 1 : Executive Council

- CEO Agent
- COO Agent
- CTO Agent
- CPO Agent
- CFO Agent
- Chief AI Agent
- Chief Security Agent
- Chief Research Agent
- Chief Quality Agent

> Executive Council เป็นผู้**แปลง Vision ให้เป็นแผนงาน**

### Level 2 : Department Managers

แต่ละ Department มี Manager ของตัวเอง เช่น:

- Engineering Manager
- Media Manager
- Language Manager
- Cloud Manager
- Research Manager
- Security Manager
- Operations Manager
- Documentation Manager
- Automation Manager

### Level 3 : Specialist Agents

แต่ละทีมมีผู้เชี่ยวชาญ เช่น Backend · Frontend · AI · Voice · Video · Database · Analytics · Localization · SEO · Marketing · Legal · Finance · DevOps · QA · Documentation ฯลฯ

(รายชื่อเต็มแยกตาม Department: [NIRVA_ORG_BLUEPRINT_PHASE1.md](NIRVA_ORG_BLUEPRINT_PHASE1.md))

### Level 4 : Reviewer Agents

- Architecture Reviewer
- Security Reviewer
- Performance Reviewer
- Code Reviewer
- UX Reviewer
- Legal Reviewer
- AI Quality Reviewer

> **ทุกงานต้องผ่าน Reviewer ก่อน**

### Level 5 : Learning Agents

รวบรวม:

- Lessons Learned
- Best Practices
- Errors
- Success Cases
- Failed Cases

ส่งเข้า **Nirva Knowledge Hub** เพื่อให้ AI ทุกตัวเรียนรู้ร่วมกัน

---

## กฎการทำงาน (10 ข้อ)

1. ไม่มี Agent ใดทำงานนอกหน้าที่โดยไม่มีเหตุผล
2. ทุกการเปลี่ยนแปลงต้องบันทึก
3. ทุกการตัดสินใจต้องอธิบายได้
4. ทุกระบบต้องมีเจ้าของ (Owner)
5. ทุกงานต้องมีผู้ตรวจสอบ
6. ทุก Agent ใช้มาตรฐานเดียวกัน
7. ทุกความรู้เข้าสู่ Knowledge Hub
8. ทุก API และ Workflow ต้องมีเอกสาร
9. ทุก Agent ต้องรองรับการเปลี่ยนผู้ให้บริการ AI
10. ทุกโมดูลต้องออกแบบให้ขยายได้ในอนาคต

## Agent Memory

ทุก Agent มี:

| Memory | ขอบเขต |
|--------|--------|
| Short-term Memory | บริบทงานปัจจุบัน |
| Project Memory | ความรู้ระดับโปรเจกต์ |
| Organization Memory | ความรู้ระดับองค์กร |
| Knowledge Memory | ความรู้สะสมทั้งหมด |

> แต่ใช้ **Knowledge Hub เป็นแหล่งข้อมูลกลาง**

## AI Marketplace (อนาคต)

Nirva รองรับการเพิ่ม Agent ใหม่ได้ เช่น:

- Medical Agent
- Education Agent
- Accounting Agent
- Legal Agent
- Construction Agent
- Manufacturing Agent
- Agriculture Agent
- Tourism Agent
- Real Estate Agent

> Developer สามารถสร้าง Agent ใหม่และเชื่อมเข้าระบบได้ผ่าน**มาตรฐานเดียวกัน**

---

## เป้าหมายสูงสุด

Nirva ไม่ใช่เพียงระบบ AI แต่เป็น **"AI Operating Platform"** ที่สามารถสร้าง:

- AI ใหม่
- Workflow ใหม่
- Business ใหม่
- Ecosystem ใหม่

โดยใช้**โครงสร้างกลางเดียว** — ทุกผลิตภัณฑ์ ทุก Agent และทุกบริการสามารถทำงานร่วมกันได้อย่างเป็นระบบ และเติบโตไปพร้อมกัน
