# Nirva AI upstream snapshot

This folder preserves the Nirva Media work authored in the original
`Nirvacore/nirva-AI` repository. Files in this snapshot were copied without
rewriting their implementation.

- Source branch: `claude/nirva-media-nle-vision-h0v1z0`
- Source handoff commit: `12b7034`
- Original merged PR: `Nirvacore/nirva-AI#59`

## Included source

- `server/media/` and `server/api/nmd.ts`
- NMD and media test suites
- `shared/media.ts`
- Original `apps/nirva-studio-os/`
- React Native/Expo `mobile/`
- TypeScript, Python, and Go `sdk/`
- Phase 13–17 architecture roadmaps

New product work lives outside this folder. This keeps the upstream snapshot
auditable and prevents accidental rewrites from being presented as original
work.
