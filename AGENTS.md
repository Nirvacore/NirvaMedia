# Nirva Media working memory

`docs/UPSTREAM_HANDOFF.md`. Treat those files as the current product and source
boundaries. Update the product memory whenever repository ownership, packaging,
deployment, platform coverage, or the next implementation priority changes.

the product in the active application and extract upstream code only through an
explicit adapter or package.
