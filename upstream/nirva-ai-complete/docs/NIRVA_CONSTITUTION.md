## Founder Statement

Nirva มีเป้าหมายในการสร้าง **AI Operating System และ Ecosystem** ที่ช่วยให้บุคคล องค์กร และสังคม สามารถสร้าง ทำงาน เรียนรู้ และเติบโตได้ด้วย AI อย่างเป็นระบบ ปลอดภัย และขยายได้ในระยะยาว

> Nirva ไม่ใช่เพียงซอฟต์แวร์ แต่เป็น**แพลตฟอร์มกลาง**ที่ทุกผลิตภัณฑ์ใช้โครงสร้างเดียวกัน

## Development Policy

### AI Coding Agent มีหน้าที่

- วิเคราะห์ความต้องการ
- ออกแบบระบบ
- เขียนโค้ด
- เขียน Unit Tests
- เขียน Integration Tests
- สร้างเอกสาร
- ตรวจสอบคุณภาพ
- วิเคราะห์ประสิทธิภาพ
- เสนอการปรับปรุง
- สร้าง Pull Request
- แก้ไขข้อผิดพลาด
- สร้าง Release Notes

### มนุษย์มีหน้าที่

- กำหนดวิสัยทัศน์
- อนุมัติการเปลี่ยนแปลงสำคัญ
- ตัดสินใจเชิงธุรกิจ
- กำกับดูแลด้านกฎหมาย ความปลอดภัย และจริยธรรม

## Ultimate Goal

สร้าง Ecosystem ที่สามารถสร้าง**ผลิตภัณฑ์ใหม่ โมดูลใหม่ AI Agent ใหม่ และธุรกิจใหม่**ได้จากโครงสร้างพื้นฐานเดียว

ทุกองค์ประกอบต้องสามารถเชื่อมต่อกัน ใช้ซ้ำได้ ขยายได้ และดูแลรักษาได้ในระยะยาว โดยมี**มนุษย์เป็นผู้กำหนดทิศทาง** และ **AI เป็นผู้ช่วย**ในการออกแบบ พัฒนา ทดสอบ และปรับปรุงระบบอย่างต่อเนื่อง
