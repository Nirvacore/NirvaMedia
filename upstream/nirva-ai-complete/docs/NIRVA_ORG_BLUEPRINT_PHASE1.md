## หลักการสำคัญ

1. Agent ทุกตัวมีหน้าที่เดียว (**Single Responsibility**)
2. สื่อสารกันผ่านมาตรฐานเดียว เช่น API หรือ Event
3. ทุกความรู้เก็บเข้า **Nirva Knowledge Hub**
4. ทุกงานต้องผ่านการ **Review** ก่อนเสมอ
5. ทุก Agent ต้องอ้างอิง **Design System** และ **Architecture กลาง**
6. ทุกการเปลี่ยนแปลงต้องบันทึกและตรวจสอบย้อนหลังได้
7. ออกแบบให้เพิ่ม Agent ใหม่ได้โดยไม่กระทบระบบเดิม
